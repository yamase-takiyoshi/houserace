📺 X96 映像・音声翻訳

自宅でも外出先でも同じ画面を開ける操作ポータル。X96の翻訳サーバーと、YouTube・DRMなし動画への入口です。

🏠 自宅のX96

iPadとX96が同じLANにある場合。

X96本体の8766番 ↗

写真でアクセスできた192.168.123.143を初期値にしています。IPが変わった場合は修正してください。8766番に直接アクセスする場合は http://192.168.123.143:8766/ に変更してください。

🌏 外出先のiPad

自宅X96とiPadをZeroTier One（またはTailscale）で同じ仮想LANにつないで使用します。

ZeroTierの接続設定ガイド ↗ZeroTier Central ↗

IPVanish単独では自宅X96のLANには入れません。ZeroTier Oneで同じプライベートネットワークに参加し、Centralで両端末をAuthorizeしてください。X96のManaged IPを入力します。iPadではIPVanishとの同時利用は難しいため、必要に応じてVPNを切り替えてください。X96側サーバーはVPNからの接続を許可してください。

▶ ChromeのYouTube・DRMなし動画

動画のURLを貼り付けて、Chromeなどで開きます。

現段階では動画を開く機能のみ。YouTubeの音声をChromeから直接取得して翻訳する機能は、X96側に別途実装が必要です。

🔊 日本語の音声テスト

この端末の日本語読み上げを確認します。

読み上げのテストです。英語音声の認識・翻訳ではありません。

手元のMP4・WebMなどを選択して、このブラウザで再生できます。ファイルはGitHubにアップロードしません。

📦 v0.4 Androidアプリ・APKビルド

Android 11 の録音許可で、取得が許可された動画アプリの内部音声をX96へ送信する補助アプリです。現在GitHubにソースとビルド設定を配置しています。APKのビルド成功・X96実機での動作はまだ確認されていません。

GitHub ActionsでAPKを確認 ↗ Androidアプリのソース ↗

GitHub Actionsの実行が成功した場合、該当RunのArtifactsに「X96-App-Audio-Capture-APK」が表示されます。未表示・失敗時はインストール用APKは完成していません。

使い方と対応状況

  1. 自宅X96で既存の翻訳サーバー v0.2 を起動します。
  2. 自宅では「自宅のX96」を押します。
  3. 外出先では両端末にZeroTier Oneを入れ、同じネットワークに参加してCentralで承認し、X96のManaged IPで開きます。
  4. ChromeのYouTubeまたはDRMなし動画は「動画URL」欄で開きます。

現在使える機能：動画ページ起動、ローカルファイル再生、サーバーへのリンク、日本語読み上げテスト。
未実装：Chrome再生音声の自動取得・認識・日本語翻訳・同期再生。GitHub PagesのHTML単体では実現できず、X96側の処理機能が必要です。

GitHub PagesはHTTPSのため家庭内HTTPへのAPI通信はブラウザの制限を受けます。この画面では新しいタブで開く方式を採用しています。LANサーバーをインターネットへ直接公開したり、GitHub上に接続トークンを保存したりしないでください。

GitHub上にはHTML画面だけが置かれます。音声データ・動画・翻訳モデルはX96で処理する構成です。
