X96 X6 / ANDROID 11 / IPAD

🌏 ZeroTier One 遠隔アクセス設定

自宅のX96翻訳サーバー（8766番）を、外出先のiPadから安全な仮想LAN経由で開くための手順です。ルーターのポート開放は不要です。

目標の接続経路

自宅 X96（ZeroTier One）　⇄　ZeroTierの暗号化仮想LAN　⇄　外出先 iPad（ZeroTier One）

GitHub Pagesには操作用HTMLのみを配置。翻訳処理と接続トークンはX96側に残します。接続トークンをGitHubや一般公開ページに記載しないでください。

1

ZeroTierネットワークを作成

ZeroTier Centralでプライベートネットワークを作成し、表示された Network ID（16桁）を控えます。Network IDをこのページへ入力する必要はありません。

ZeroTier Centralを開く ↗
2

X96へZeroTier Oneを導入

X96（Android 11）のGoogle Playで「ZeroTier One」をインストールします。Android TVのPlayストアで表示されない場合は、公式配布元を確認してください。アプリでNetwork IDを入力して参加します。VPN許可画面が出たら許可してください。

公式ダウンロード ↗
3

iPadにもZeroTier Oneを導入

App StoreでZeroTier Oneを入れ、同じNetwork IDへ参加します。VPN構成の追加を許可します。IPVanishが有効なら、まず一時停止してZeroTier側を接続してください。

iPad版を入手 ↗
4

Centralで両端末を承認

ZeroTier Central → ネットワーク → Member Devices → X96とiPadをそれぞれ Authorize。X96側に割り当てられた Managed IP を確認します（10.x.x.x や192.168.x.xなど）。

ここで必要なのはiPadのIPではなく、X96のZeroTier側のIPです。例示IPは使わないでください。

5

外出先からX96を開く

IPとポートはこのブラウザ内のみに保存します。GitHubへ送信しません。

このページはHTTPS、X96はHTTPなので、ページ内で自動接続テストはできません。「開く」でSafariの新しいタブへ移動して動作確認してください。外出先でのテストは自宅Wi-Fiを使わず行ってください。

🛠 つながらない場合

  1. X96でZeroTierがオンラインになっているか確認する。
  2. Centralで両端末ともAuthorizeされ、X96にManaged IPがあるか確認する。
  3. iPadでIPVanishを一時停止し、ZeroTier VPNを有効にする。
  4. X96のChromeで http://127.0.0.1:8766/ が開くか確認する。
  5. X96のTermuxで次のコマンドを実行して、サーバーがどのアドレスで待ち受けているか調べる。
ss -ltn | grep 8766

「127.0.0.1:8766」のみなら外部端末から直接到達できません。サーバーをZeroTierから届くインターフェースでも受け付ける設定にする必要があります。ただし既存の設定は変更せず、結果を確認してから調整してください。

8766番が正常でも翻訳が止まる場合は、VPNではなくWhisperなどの処理側を別途確認します。

既存の8766翻訳サーバー／8765競馬サーバーには、このHTMLから設定変更を加えません。外部への直接ポート公開は避けてください。
